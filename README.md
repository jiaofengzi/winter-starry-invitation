# 冬季星空 · 礼物交换

现有星空邀请函静态动画的 GitHub Pages 部署副本。原始 `index.html` 和配乐保持不变。

访问：https://jiaofengzi.github.io/winter-starry-invitation/

## 当前版本

点击「开始」播放星空返航动画；右下角可切换声音，播放结束后左下角可重播。需要支持 WebGL 和 Web Audio 的浏览器。

本版本邀请正文由原作者暂时隐藏，日期、地址、规则和名单仍含占位符；此次仅部署，不补写或公开真实参会人信息。

## 发布与维护

使用 GitHub 官方 Pages：`main` 分支、根目录发布；`.nojekyll` 禁用 Jekyll 转换。更新静态文件后 push 到 main 即自动发布，无需本地进程、临时隧道或 Hermes 补丁。

仅发布入口与其所需音频；不包含旧版本、参考页面、编辑器配置及音频源文件。
